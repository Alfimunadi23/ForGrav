# ForGrav

ForGrav adalah aplikasi Forward Modelling Gravity berbasis Python yang dikembangkan
untuk pemodelan anomali gravitasi 2D menggunakan formulasi Talwani (1959).

## Fitur
- Forward modelling gravitasi 2D
- Visualisasi model poligon
- Perhitungan anomali gravitasi
- Dibangun menggunakan Python
